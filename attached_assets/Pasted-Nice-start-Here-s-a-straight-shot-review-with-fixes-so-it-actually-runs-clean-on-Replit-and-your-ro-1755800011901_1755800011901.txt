	1.	Swagger UI not generating

	•	You set add_specs=False, which disables /swagger.json, so /api/docs/ will be empty.
	•	Fix: remove it or set add_specs=True.

    description='ACA/Medicare Plan Comparison API',

    # remove add_specs=False

	3.	Frontend demo file path is brittle

	•	../frontend/src/demo.html will 404 if your repo layout differs.
	•	Fix: use send_from_directory and a safer root.

from flask import send_from_directory

@app.route('/')
def serve_frontend():
    root = os.path.abspath(os.path.join(os.path.dirname(__file__), '..'))
    demo_dir = os.path.join(root, 'frontend', 'src')
    demo_file = 'demo.html'
    if os.path.exists(os.path.join(demo_dir, demo_file)):
        return send_from_directory(demo_dir, demo_file)
    return jsonify({...})

	4.	WeasyPrint on Replit

	•	WeasyPrint needs system libs (Pango, Cairo). Replit often lacks them; install may fail.
	•	Pragmatic alt: ship HTML now and add PDF later, or switch to pure-Python xhtml2pdf for MVP. If you keep WeasyPrint, add a try/except fallback:

try:
    from weasyprint import HTML, CSS
    weasy_ok = True
except Exception:
    weasy_ok = False

Then in /export/pdf, if not weasy_ok, return the HTML download instead.
	5.	Content ingestor dependency

	•	/api/content/search calls worker.hcgov_ingest.get_ingestor(). If that module isn’t present, you’ll 500.
	•	Fix: add a stub that loads a small in-memory corpus so the endpoint works now.

# worker/hcgov_ingest.py
_cached = [{"title":"Premium","url":"https://www.healthcare.gov/glossary/premium/","text":"..."}]

class Ingestor:
    def search_content(self, q, limit=10):
        ql = q.lower()
        hits = [r for r in _cached if ql in r["title"].lower() or ql in r["text"].lower()]
        for h in hits: h["match_snippet"] = h["text"][:220] + "..."
        return hits[:limit]
    def get_content_stats(self): return {"docs": len(_cached)}

_singleton = Ingestor()
def get_ingestor(): return _singleton
